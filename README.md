# Los 14 de Renata 💜

Felicitación interactiva para el cumpleaños 14 de Renata, hecha por Andy.

Tiene 6 etapas: regalo sorpresa → pastel con 14 velitas para soplar → prueba de moda → mini juego "atrapa 14 sushis" → galería de fotos tipo polaroid → carta.

## Cómo verla

Abre `index.html` en el navegador (doble clic). No necesita instalar nada; la música se genera con Web Audio desde el mismo código.

## Archivos

- `index.html`: toda la página (HTML, CSS y JavaScript en un solo archivo).
- `img/`: las fotos (`andy.jpg` y `f01.jpg` a `f12.jpg`).
